## 目的

MRデバイスでプレゼンテーションを表示し、プレンテイターがオーディエンスに対しプレゼンを行う一連のシステム

## スコープ

- やること
  - json形式のプレゼンデータを読み取り、Unityのオブジェクトとして変換できる仕組みを作成する
  - プレゼンテイターにしか見えない操作盤を作成する
- やらないこと
  - 同期処理作成
  - ルーム機能の作成
  - アカウント作成・ログイン
  - UI・デザインの改善
  - 軽量化・最適化
  - オーディエンス側のUI

## 機能要件

- json形式のプレゼンデータを読み取り、Unity用にプレゼンを構築する
- プレゼンテイターがプレゼンを操作するための最低限の入力をできるようにする(前後のスライドへ移動など)

## 非機能要件

なし。6月までは最低限

## 受入条件

「ここまで動けば、このレイヤーの要件定義は満たされた」と言える条件。
TDDのテストケースに落とせる粒度で書くと後の作業が楽。

- [x] MR - [パススルーを取得し、MR空間を描写・MR開発ができる状態]

- [ ] json - [jsonファイルを取得し、Unity内で読み取りが可能な状態に ]
- [ ] プレゼン構築 - [jsonファイルを読み取り、オブジェクトを生成・プレゼンを構築できる状態 ]

- 依存する他レイヤー / 外部サービス / ライブラリ:
  - OpenXR meta
  - XRツール

  - Webアプリからのjsonファイル
