# 6月発表会MVP定義書

## 目的

**2026-06-07** まで **実質 2 週間** で「動くものを見せる」ための縮小版実装計画。
完全版設計書を**置き換えない**。今回限定の差分を定義する。

---

## ゴール

> Webアプリで作ったスライドがバックエンドを通してローカルデータベースに保存され、MR デバイス、今回はmeta quest 3がそれを取得して空間に表示し、コントローラーで移動・回転・拡大できる

ビジネス要件「作成 → 表示」のエンドツーエンドを、1 スライス（1 スライド）で 6/7 までに通すことが MVP。

---

## スコープ（やること）

### WebApp（颯士担当）

**1 スライド編集アプリ**。

- `.fbx` ファイルのアップロード
- スライドのテキスト入力（1 要素）
- 3D プレビューでモデルの position / rotation / scale を調整
- 「保存」ボタンで Backend に永続化

### Backend（颯士担当）

**localhost 動作の最小 API サーバー**。

- マニフェスト返却（MR が読む）
- アセット静的配信（`.fbx` ファイル）
- WebApp からのアップロード受信・スライド保存
- DB に永続化（複数 presentation・認証なし）

### MR（和貴担当）

**Unity による MR 表示クライアント**。

- マニフェスト取得 → `.fbx` を HTTP ダウンロード → シーン配置
- コントローラーでモデルの移動・回転・拡大縮小
- スライドのテキストを空間表示
- プレゼンテイター 1 人のみ。観客同期は MVP 外

---

## スコープ外（発表会後に積む）

### Phase α（7 月以降）

- WebApp の機能拡張（マルチスライド・並び替え・Undo/Redo・Auto Save・バリデーション UI）
- 複数モデル / 複数テキスト / 画像要素
- MR からの transform 書き戻し

### Phase β 以降

- 認証 / ログイン UI
- クラウド本番環境（Cloudflare / AWS）への移行
- リアルタイム同期 / 複数人接続 / オーディエンス参加
- ルームキー / ゲストセッション / 個別閲覧空間
- `.obj` 等の追加形式対応 / LOD / アセット最適化

## 縦スライス（優先順位）

上から順に動くようにする。

1. 和貴が単独完結で Unity に `.fbx` を 1 個取り込んでコントローラーで動かせる
2. 颯士の Backend がマニフェストと `.fbx` ファイルを HTTP で返せる
3. Unity が Backend から `.fbx` を取得 → ランタイムロード → シーン配置（MR 側エンドツーエンド完成）
4. WebApp で `.fbx` アップロード + テキスト入力 + プレビュー + 保存ができ、Unity 側を再起動すると反映される（**作成 → 表示の全体完成**）
5. WebApp のプレビュー上で transform 編集ができる
6. テキスト要素を空間に表示できる
7. 発表シナリオ整備・通しリハ・デモ動画録画

## WBS（2 週間版）

> 発表日 **2026-06-07**

### W0（5/18-5/19）即決事項

- 3D モデル形式: **`.fbx`**（確定）
- マニフェスト型の合意（実装時に共有定義として確定）
- DB スキーマの合意（実装時に共有定義として確定）
- WebApp 実装する（確定）
- リポジトリ構成（モノレポ or 各自リポ）

### W1（2026-05-19 〜 2026-05-25）

**和貴 / MR**

- Unity プロジェクト作成、必要パッケージ導入
- 実機で空シーンが MR モードで起動する
- ローカル `.fbx` を 1 個コントローラーで Grab / Move / Scale できる（縦スライス 1）
- Backend への HTTP GET の素振り

**颯士 / Backend + WebApp**

- Backend 起動、マニフェスト返却 + アセット静的配信（縦スライス 2）
- WebApp からのアップロード受信・スライド保存 API
- Unity 実機から到達できるネットワーク設定
- WebApp 起動、`.fbx` アップロード + テキスト入力 + 保存までの一連
- 3D プレビューで `.fbx` を表示

**共通 / W1 末の疎通会（必須）**

1. 和貴の Unity 実機 → 颯士の Backend → マニフェスト取得 + `.fbx` ダウンロードまで通る
2. 颯士の WebApp → アップロード + 保存 → Unity 再起動で新モデルが MR に反映される
