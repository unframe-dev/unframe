# Unframe Scrapbox ユーザー反応まとめ

対象: `Unframe_Scrapbox.json`

## 概要

Unframe に対する反応は、全体として「3D モデルをプレゼンに組み込む発想は面白い」という期待がある一方で、「MR である必然性」「スライド形式である必要性」「実際のユースケース」「既存ツールとの差分」に対する問いが非常に多い。

単純な否定というより、プロダクトの芯をより明確にするための指摘が多い。特に、MR そのものへの関心や期待はあるが、現時点では「3D を見せる価値」と「MR で見せる価値」が混ざって見えている。

## ポジティブな反応

### アイデアの新規性・面白さ

- 3D でスライドが見られるというアイデアが斬新で面白い。
- 迫力のあるプレゼンになりそうで使ってみたい。
- 「プレゼンを MR にする」という発想自体に可能性を感じる。
- 2D では伝わりにくいものを 3D で見せられるのは魅力的。
- 「見ればわかる」ような発表体験を作れそう。
- 最終成果発表会を Unframe でやってほしい、という期待もあった。

### 3D モデル活用への期待

- ハードウェア系のプロジェクトと相性が良さそう。
- 実機を会場に持っていくのが大変な場合、3D モデルを資料に組み込めるのは助かる。
- 点群データ、CAD モデル、建築モデルなどを見せる場面で使いたい。
- 3D モデルを 360 度見られるようにすると、資料共有時にも引き込まれやすい。
- 立体物のスケール感や構造理解には、3D 表示が有効そう。
- ざっくりと形が分かればよい場面もあり、3D の精度が完璧でなくても価値が出る可能性がある。

### インタラクションへの期待

- 視聴者が発表中に 3D モデルを自由に回転・分解・観察できると良い。
- 発表者の進行に同期しながら、視聴者ごとに自由な視点で見られる体験に価値がありそう。
- 3D モデルにレーザーポインター的にポインティングできると便利。
- Zoom の画面共有メモのように、3D プレゼンを見ながら書き込みできると良い。
- 一方向の発表ではなく、双方向的なインタラクションが本質的な差分になりそう。

### MR/VR/AR 表現への期待

- 部屋の 4 面を使ったプレゼンなど、2D ではできない演出ができそう。
- Z 軸方向のエフェクト、奥行きのあるテキスト、立体的なトランジションに期待がある。
- ステージのライティングを変えるような、空間演出の需要がありそう。
- かわいいキャラクターが MR で一緒にプレゼンしてくれるような体験も面白そう。
- VRChat や技術集会のような場と組み合わせると可能性がありそう。
- デカい地球や星空、3D グラフなど、スケールのある表現に向いていそう。

### 既存プレゼン体験の拡張としての期待

- PowerPoint や Keynote の代替ではなく、3D を扱うプレゼン体験の拡張として期待されている。
- `.pptx` や `.pdf` をインポートし、そこに 3D コンテンツを載せられると使いやすそう。
- 普通にインタラクティブな Three.js がスライドについているだけでも欲しい、という反応があった。
- ブラウザや PC でも 3D モデルを回せるビューアがあると嬉しい。
- 既存資料を活かせると、導入障壁が下がる。

## ネガティブ・懸念の反応

### MR である必然性が弱い

最も多かった懸念。3D を扱う価値は伝わっているが、それが MR でなければならない理由がまだ弱いと見られている。

- 3D モデルを表示するだけなら、ブラウザの Three.js ビューアでよいのでは。
- 2D スライド上で 3D モデルを回せるだけでも十分では。
- 動かない 3DCG は画像でよい。
- 誰から見ても同じように動く 3DCG は動画でよい。
- 視聴者ごとの視点で見る意味があって初めて 3DCG の価値が出るのでは。
- MR による立体感より、Quest などを装着する負担の方が大きく感じる。
- 3D である価値と MR である価値が混ざっており、MR 固有の価値が見えにくい。

### スライド形式である必要性への疑問

MR 空間を使うなら、長方形のスライドに縛られる必要があるのか、という指摘が多い。

- そもそもスライドである必要はないのでは。
- MR 空間で長方形の枠にとらわれる理由がわからない。
- 新しいプレゼンテーションの仕組みを発明してほしい。
- スライドという 2D 形式を MR に持ち込むメリットが不明。
- プレゼンテーションは情報を要約するものだが、MR は実空間に情報を重ねるため、両者が相反する可能性がある。
- デモを見た感じ、スライドではない方向にも可能性がありそう。

### ユースケースがまだ定まっていない

誰が、どこで、何人で、何のために使うのかが曖昧という反応。

- プレゼンと言っても、1on1、少人数、授業、大規模カンファレンスでは体験が全く違う。
- 物理的に近い場で使うのか、遠隔で使うのかが気になる。
- 物理的に近い場を想定するなら、VR/MR のメリットが薄い可能性がある。
- 少人数には向かないかもしれない。
- 大人数では全員が MR デバイスを装着するのは現実的でない。
- N 高の進捗説明会が本当に課題なのか、実際のペインがあるのか精査すべき。
- 問題を恣意的に作っているように見える、という強めの指摘もあった。
- ユーザーのペインポイントが薄いのでは、という反応があった。

### デバイス装着・普及面の負担

MR/VR デバイス前提の導入障壁に対する懸念。

- MR デバイスを持っている人は少ない。
- オフライン会場に MR デバイスを持ってくる人はさらに少ない。
- 全員 Quest 装着はつらそう。
- 5 人以上のプレゼンで全員が Quest をつけるユースケースは想像しづらい。
- XREAL ならまだしも Quest は重い、というニュアンスの意見があった。
- スマホをかざしながらプレゼンを見るのも若干きつそう。
- デバイスが必須なら導入障壁が高い。
- PC、スマホ、固定カメラの 2D 版などのフォールバックが必要ではないか。

### 既存ツールとの差分が見えにくい

既存のプレゼンツール、3D ビューア、CAD、VR プラットフォームとの差分を問う声。

- PowerPoint や Keynote でも 3D モデルを扱える。
- CAD 画面共有や 3D 描画ソフトと切り替えて見せることと何が違うのか。
- ブラウザでインタラクティブに表示するだけでよいのでは。
- cluster、VRChat、Resonite 上で 3D モデルを見ながらプレゼンできればよいのでは。
- 既存プレゼン作成アプリから乗り換えるだけの user value があるのか。
- 友達に何と言ってこのアプリを使ってもらうのか考えるべき。

### 素材・アセット戦略への疑問

3D 素材を大量に用意する必要があるという課題設定への疑問。

- スライド作成用素材の量の確保が大変という話が唐突に見える。
- プリセットの 3D モデルを大量に用意する前提なのかがわかりにくい。
- ユーザーが `.obj` や `.fbx` をアップロードする形では難しいのか。
- アプリ側で素材を大量に用意しなくてもよいのでは。
- MeshyAI などで 3D モデルを生成する案もある。
- Canva / PowerPoint のように豊富な初期素材を用意する方向に行くと、スコープが大きくなる可能性がある。

### 技術・実装面の不安

- 3D 空間エディターを作るならかなり高度になりそう。
- 3D モデルのマテリアルや Shader をどこまで編集できるようにするのかが不明。
- 表現力を上げるほど実装も UI も重くなりそう。
- 3DCAD はただでさえ重いため、パフォーマンスが心配。
- 複数端末で同じ空間を見る場合、遅延問題が起きそう。
- 視聴者ごとに映像を見るのか、同じ画面に 3D モデルを重ねるのかで技術課題が変わる。
- 多数派デバイスへの対応を優先すると、MR ゴーグル側の体験品質が下がる可能性がある。
- AI やアクセシビリティとの相性が悪そうという懸念があった。

### プレゼン体験としての見づらさ

- スライドに固定された 3D モデルが本文を隠す可能性がある。
- デモで 3D モデルや文章が PC 側と MR 側で異なっていた点が気になった。
- スライドと 3DCAD 画面を切り替えるような操作は、発表慣れしていないと無言の操作時間になり、聴衆の集中が切れそう。
- 視聴者が自由に見るのか、発表者が動かして見せるのかが曖昧。
- 個別閲覧なのか、オーディエンスが歩き回って見るのか、体験イメージにズレがある。

### プロダクトの起点・方向性への疑問

- これは課題解決のために生まれたものなのか、MR プレゼン自体の面白さから生まれたものなのか。
- 元の実体験と、今解こうとしている課題が完全に一致していない可能性がある。
- 問題解決プロダクトなら、現場に行って何が辛いかヒアリングすべき。
- MR プレゼン自体の面白さに取り組んでいるなら、無理に N 高のユースケースに絞らなくてもよい。
- 意思を貫いてもよいし、ピボットしてもよい、という反応もあった。

## 機能提案

### 閲覧・発表機能

- 視聴者が 3D モデルを自由に回転できる機能。
- 視聴者が 3D モデルを分解して見られる機能。
- 視聴者ごとの個別閲覧。
- 発表者の操作に同期して 3D モデルが動く視聴用ページ。
- PC やスマホ向けの 2D ビューア。
- 固定カメラの 2D 版フォールバック。
- プレゼンター用の発表者ノートを空間上に表示する機能。
- 3D モデルへのポインティング機能。
- 3D プレゼンへの共同書き込み。

### 作成・編集機能

- `.obj`、`.fbx` などの 3D モデルをドラッグアンドドロップで読み込む。
- `.pptx` / `.pdf` のインポート。
- 既存資料に 3D コンテンツを追加できる仕組み。
- キーフレームでアニメーション設定。
- 高度な 3D 空間エディター。
- マテリアルや Shader の設定。
- Slidev や Remotion 的なコードベースのプレゼン作成。
- LLM に編集させられるプレゼン作成ワークフロー。
- AI にプレゼンを作らせる機能。

### 配信・同期・ネットワーク

- サーバーにアップロードしてロード。
- LAN 内で P2P 接続してロード。
- 遠隔地でのプレゼン対応。
- 複数会場で、スライド・発表者・モデルをリアルタイム表示。
- 発表者の動きをトラッキングして、遠隔地でも現地のように見る体験。
- VR / MR / PC / スマホなど複数プラットフォーム対応。

### 表現・演出

- ステージライティングの変更。
- 2D ではできない Z 軸方向のアニメーション。
- 強調したい文章が手前に出てくる表現。
- 3D レイヤーイラストのような没入プレゼン。
- キャラクターが一緒にプレゼンしてくれる表現。
- 4D ライブ配信的な表現。
- 3D グラフや星空への没入。

## 挙がったユースケース

### ハードウェア・プロダクト発表

- 実機を持ち運ばず、3D モデルで説明する。
- ハードウェア系 PJ の発表に使う。
- 形状、サイズ、構造を説明する。
- ちゃんと動くプロトタイプではなく、形を議論するためのプロトタイプとして使う。

### 建築・都市・インテリア

- 建築 CAD モデルを見ながら説明する。
- 建物の中に入り、歩きながら要所で説明する。
- マンション販売で、物理模型やプロジェクションマッピングの代わりに MR モデルを見せる。
- 実空間に建物を重ねて説明する。
- 都市開発やインテリア提案に使う。

### 製造業・現場支援

- 大型製造業の現場で、遠隔地の技術者が作業者に組み付け方法を説明する。
- 工場や現場で、実物に注釈を重ねて説明する。
- 技術的なレクチャーに使う。

### 教育・研究・展示

- 点群データや 3D グラフを説明する。
- 博物館のような、平面にとらわれない展示プレゼン。
- メディアアートやインスタレーションのデモ。
- 研究室での作品説明。
- 星や音楽など、抽象的なデータを没入的に見せる。

### 遠隔・分散プレゼン

- 複数会場で同じプレゼンを共有する。
- 現地ではない別会場に発表者やモニターを MR 表示する。
- VRChat やメタバース空間でプレゼンする。
- 遠隔でも現地に近い発表体験を作る。

## 反応から見える主要論点

### 論点 1: MR でしかできない体験は何か

現状では「3D を扱える」ことは伝わっているが、「MR である必要」がまだ伝わりきっていない。

有力そうな方向は、単なる 3D 表示ではなく、発表者の進行に同期しつつ、視聴者が各自の視点で 3D モデルを観察・分解・注釈確認できる体験。

### 論点 2: スライドを残すのか、捨てるのか

スライドを残すなら、既存プレゼンの文脈を活かせる一方で、MR 空間の自由度を殺す可能性がある。

スライドを捨てるなら、新しい体験を作れる一方で、作成 UI が難しくなり、既存ユーザーには使いにくくなる可能性がある。

### 論点 3: 誰向けに作るのか

候補は大きく分かれる。

- N 高など、MR/VR デバイスが配布されている環境。
- ハードウェア・建築・CAD・製造業など、立体物の説明が重要な人。
- VRChat やメタバース空間に慣れた人。
- プレゼン動画や空間演出を作りたいクリエイター。

このどれを主対象にするかで、必要機能も説明の仕方も変わる。

### 論点 4: デバイス前提をどう扱うか

MR デバイス前提にすると体験の尖りは出るが、導入障壁は高い。

PC / スマホ / 2D ビューアを用意すると使いやすくなるが、MR ならではの体験が薄くなる可能性がある。

コメント上では、MR 体験を主軸にしつつ、2D フォールバックを用意する方向が最も受け入れられやすそう。

## まとめ

Unframe への反応は、全体として期待と懸念が両方強い。

ポジティブな評価は、「3D モデルをプレゼンに自然に組み込めること」「立体物を説明する発表に使えそうなこと」「視聴者が自由視点で見られる可能性」に集まっている。

ネガティブな評価は、「MR である必然性がまだ弱いこと」「スライド形式に縛られる理由がわからないこと」「デバイス装着の負担が大きいこと」「既存ツールとの差分が見えにくいこと」に集まっている。

現時点で一番筋が良さそうな説明は、以下のような方向。

> Unframe は、発表者の進行に同期しながら、視聴者が各自の視点で 3D モデルを観察・分解・注釈確認できる、立体物のためのプレゼン体験を作る。

この方向に絞ると、MR である理由、視聴者ごとの自由視点、3D モデルを扱う必然性、ハードウェア・建築・CAD などのユースケースをまとめて説明しやすくなる。
