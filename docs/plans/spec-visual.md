# デモ向け Gesture・VFX・Animation

ステータス: 演出案（2026-11-04）。追加演出の実装・実機動作は未確認。

## 目的と範囲

[デモプレゼンの構成](demo-presentation.md)に合わせ、フレームワーク・MR App 側に追加する演出を整理する。制作時間を考慮し、左右のウェーブ、粒子化による退場、手元の発光・残光を優先する。

- **Gesture**: 発表者の動作を入力として認識するもの。
- **VFX**: 光・波・粒子などの視覚表現。
- **Animation**: 表示物が時間とともに変化する演出。粒子化による退場は Animation として扱い、その表現に VFX を使う。

既存の移動・拡大縮小・回転は、今回追加する演出の対象に含めない。

## Gesture

### 新規追加する案

| Gesture  | 動作                             | 組み合わせる演出                                   |
| -------- | -------------------------------- | -------------------------------------------------- |
| 投げる   | つかんだものを放すように腕を振る | 手元から粒子や光を放ち、文字・画像の登場につなげる |
| 円を描く | 片手で空中に円を描く             | 手の軌跡で光の輪を描く                             |

認識方法・成立条件は未決定。投げる操作には「トリガーを押して構え、腕を振って離した瞬間に発動する」案がある。円の大きさ・閉じ方・入力の開始と終了は実装時に決める。

### 既存 Gesture の利用

| Gesture                                    | 今回の用途案                               |
| ------------------------------------------ | ------------------------------------------ |
| 両手を広げる（`SpreadHands`）              | 左右のウェーブを展開する                   |
| 左右スワイプ（`SwipeLeft` / `SwipeRight`） | 光の弧を走らせ、文字・画像の登場につなげる |

既存の認識には、ほかに上下スワイプ、前へ押す、手前へ引く、両手を閉じるがある。現在はトリガーを押しながら動かす方式で、場面ごとに有効な Gesture を受け付ける。

## VFX

| 演出               | 内容                                                                                                                 | 優先度・用途                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 左右からのウェーブ | プレゼン空間の左右の場外から複数の波線が中央方向へ伸びる。中央は空け、コンテンツの左右〜背後を包み、尾を残して消える | 優先。場面4では控えめに、場面7では両手を広げる動きに合わせて大きく展開 |
| 手元の発光・残光   | Gesture の操作中だけ手元が光り、動きに短い軌跡が残る                                                                 | 優先。身振りと演出の関係を見せる                                       |
| 粒子の消散         | 表示物からほどけた粒子が流れ、薄くなって消える                                                                       | 優先。後述の粒子化による退場を構成する                                 |
| スワイプの光の弧   | スワイプ成立時に、動いた方向へ短い光の弧が走る                                                                       | 追加候補                                                               |
| 確定時の波紋       | Gesture 成立時にリングが広がって消える                                                                               | 追加候補。ウェーブとの重なりを見て採否を判断                           |
| モデルを包む光の帯 | 波の束がモデルの周囲を一周し、尾を残して消える                                                                       | 時間に余裕があれば場面7で使用                                          |

### ウェーブの参照

見た目の参照は LP の [`GradientWave.svelte`](../../app/web/lp/src/lib/components/brand/GradientWave.svelte)。青紫〜コーラルのグラデーションを持つ、細い「〜」状の波線が複数重なる表現を使う。

参照元は静的な SVG。MR の演出では、線ごとに少し時間差を付けて端から描かれるように出現し、流れ、消える動きを追加する。中央での衝突・爆発は含めない。波はプレゼン空間に配置する。

## Animation

| 演出               | 内容                                                                                                                       | 使用場面案                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 粒子になって消える | 表示物そのものが細かな粒子へほどけ、粒子の消散とともに退場する。周囲に粒子を出すだけでなく、元の表示物が崩れる見た目にする | 場面3の当初案の退場、場面9の本編終了。左上のロゴは維持する |

文字・画像・3Dモデルのどこまで粒子化を適用するかは未決定。対象と変化の順序を決めてから実装する。

## 表示先と未決定事項

- 手元の残光は、まず HMD・ミラーリングで見せる想定。他端末でも同じ軌跡を表示する場合は、手の位置・軌跡の同期方法を別途決める。
- ウェーブなどの共通 VFX を HMD・スマートフォンに表示する範囲と同期方法は未決定。
- 投げる・円を描く Gesture の認識条件と、発火する演出の対応を確定する。
- `demo-presentation.md` の現行の退場は下方向へのフェード、閉幕はフェードアウト。粒子化への変更は本書での案であり、既存の実装や構成文書には未反映。
