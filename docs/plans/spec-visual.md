# デモ向け Gesture・VFX・Animation

[デモプレゼン](demo-presentation.md)に向けて、フレームワーク・MR App 側に追加する演出案。

## Gesture

| 演出     | 概要                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 投げる   | つかんだものを放すように腕を振る。手元から粒子や光を放つ演出につなげる |
| 円を描く | 片手で空中に円を描く。手の軌跡で光の輪を描く演出につなげる             |

## VFX

| 演出               | 概要                                                                                                                 | 備考                                                                                                                                                                                  |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 左右からのウェーブ | プレゼン空間の左右の場外から複数の波線が中央方向へ伸びる。中央は空け、コンテンツの左右〜背後を包み、尾を残して消える | LP の [`GradientWave.svelte`](../../app/web/lp/src/lib/components/brand/GradientWave.svelte) を参照。青紫〜コーラルの細い「〜」状の波線の束に、時間差を付けた出現・流れ・消失を加える |
| 手元の発光・残光   | Gesture の操作中に手元が光り、動きに短い軌跡が残る                                                                   | 優先候補                                                                                                                                                                              |
| スワイプの光の弧   | スワイプ成立時に、動いた方向へ短い光の弧が走る                                                                       | 追加候補                                                                                                                                                                              |
| 確定時の波紋       | Gesture 成立時にリングが広がって消える                                                                               | 追加候補                                                                                                                                                                              |
| モデルを包む光の帯 | 波の束がモデルの周囲を一周し、尾を残して消える                                                                       | 追加候補                                                                                                                                                                              |

## Animation

| 演出               | 概要                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| 粒子になって消える | 表示物そのものが細かな粒子へほどけ、粒子が流れて消えることで退場する。粒子の表現には VFX を使う |
