# 成果発表会 MR デモプレゼンの演出構成

ステータス: MR 本編の仮演出の Source を `example/` に実装済み（2026-11-04）。場面4以降は立方体を題材にした仮案。実際の観客の反応は未収集で、HMD・スマートフォン・ミラーリングでの見え方は実機確認が必要。場面10の通常スライド・動画は別途用意する。

## 目的と前提

- MR パート全体を、演出を重視したショーとして構成する。詳細な説明は別の通常スライドで扱う。
- 観客は HMD のミラーリングモニター、HMD、スマホ越しの MR で見る。
- 身振り、文字、画像、3D モデルを話に合わせて展開し、開発の経緯も実演しながら伝える。
- 当初案を × で切り替える導入は残し、経緯の中に「受けると思った演出と、実際に反応が良かった演出」の比較を追加する。

## 全体の流れ

セリフは意図を示すたたき台。パネルは当初案の実演に限り、転換後は透明背景の文字・図版・3D モデルで構成する。

| 場面                | 話の流れ                                         | 演出                                                                                                                                                             |
| ------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 開幕             | まずは見てもらう                                 | 何もない空間にロゴと `Unframe` がフェードイン。一拍置いて、小さくなりながら左上へ移動する。                                                                      |
| 2. 当初のプレゼン   | 「最初は、こんなプレゼンを考えていました」       | テキスト入りのパネルと 3D モデルを表示。パネルを進め、モデルを回すなど、短く普通に実演する。                                                                     |
| 3. 違和感と転換     | 「でも、スライドを空中に浮かべただけじゃない？」 | 一拍置いて × を出し、当初案ごと退場させる。ロゴは残す。                                                                                                          |
| 4. 新しい表現       | 「せっかくなら、話す動きもプレゼンにしたい」     | 身振りに合わせて文字や画像が現れ、空間に広がる。新しい表現を短く披露する。                                                                                       |
| 5. 探索の経緯       | 「この形になるまでに、いろいろ試しました」       | 当初と現在で目標が変わったこと、プロダクト面の課題、PoC を画像や短い言葉で見せる。課題 → 試作 → 発見の流れで展開する。                                           |
| 6. 予想と実際の反応 | 「回すだけなら？」「動きとつなげると？」         | 二つの演出を順に実演し、観客にも違いを体感してもらう。そこから得た気づきを短く話す。現時点では立方体の回転と、動きに合わせた文字・図版・立体の展開を仮比較する。 |
| 7. 最大の見せ場     | 「そこで、こんな表現にしました」                 | 気づきを生かし、身振り・文字・画像・3D モデルを一続きで展開する。モデルの回転・拡大・移動を組み込み、最後の構図を一拍見せる。                                    |
| 8. 技術紹介         | 「この体験を支えているのが」                     | 構成図へ切り替え、バックエンド・ネットワーク・MR・Web の役割とつながりを見せる。MR 側のエンジンやアセットもここで扱う。                                          |
| 9. 閉幕             | 「ありがとうございました」                       | 本編の要素がフェードアウト。左上のロゴと `Unframe` が中央へ戻り、開幕時の大きさになる。一拍置いてフェードアウトし、何もない空間に戻る。                          |
| 10. 通常スライドへ  | 制作と学びを振り返る                             | プレゼンテイター（発表者）視点の動画、振り返り、今後の展望へつなぐ。                                                                                             |

## 演出の軸

- ロゴと `Unframe` は開幕後から閉幕まで左上に残す。中央の演出が消える場面でも維持する。
- 開幕と閉幕を逆の動きで対応させる。閉幕は「本編が消える → ロゴが中央へ戻る → 一拍 → ロゴが消える」の順にする。
- 場面 4 は新しい表現の短い披露、場面 7 はそれを発展させた最大の見せ場にする。
- 経緯は長文パネルだけで説明せず、試した演出そのものや画像を見せながら語る。

## 開幕の確定内容

- ロゴと `Unframe` を横並びにし、背景は透明にする。ロゴは `assets/icon.glb` の 3D Model を使う。
- `example/assets/icon.glb` は現行レンダラーに合わせて UV 割当を正規化し、埋め込み画像を 1024px に縮小したもの。形状のバイナリは原本から保持し、`pnpm --filter @unframe-dev/demo-presentation prepare:logo` で再生成する。
- 0.9 秒でフェードインし、0.8 秒静止する。その後 1.3 秒かけて左上へ移動しながら 0.32 倍に縮小する。
- 移動後は表示を維持する。配置は Stage に固定し、視点には追従させない。HMD・スマートフォン・ミラーリングでの見え方は実機で確認する。
- 文字は React と Tailwind で描画する。文字と Model を同じ `scene` 配列に配置し、透明度・移動・縮小を `flow.timelines` の単一 Timeline と開始 Cue で同期する。

## 当初のプレゼン

- 仮の題材は立方体。中央左のダークパネルに2枚の説明を用意し、右にコーラルから青紫の立方体を置く。
- 通常再生中、開幕完了後に `next-scene` で登場、`next-panel` で2枚目へ進み、`rotate-cube` で10秒かけて一回転する。回転後は停止し、パネルと左上のロゴを維持する。
- パネルは `original-panel.component.tsx`、登場と回転は `original.timelines.ts` で定義する。日本語は同梱の Noto Sans CJK JP Regular を使用する。
- `example/assets/cube.glb` は `pnpm --filter @unframe-dev/demo-presentation prepare:cube` で再生成する。

## 違和感と転換

- 立方体の回転開始後、`reject-original`（`presenter.next`）で開始する。回転途中でも転換できる。転換中の追加入力は受け付けない。
- 0.6秒待った後、中央手前の赤い×を0.22秒で拡大しながら表示する。0.6秒見せてから、×・パネル・立方体を0.7秒かけて下へフェード退場させる。
- 左上のロゴと `Unframe` は維持し、次の `presenter.next` で場面4へ進むまで待機する。
- ×は `rejection.component.tsx`、演出は `rejection.timeline.ts` で定義する。HMD・スマートフォン・ミラーリングでの見え方は未確認。

## 転換後の操作と演出

`presenter.next` ごとに次の演出を開始し、完了後は話す時間を取れるよう待機する。演出中の追加入力は受け付けない。ジェスチャー認識は使わず、発表者が操作を身振りに合わせる。

| 場面             | 演出時間 | 表示・動作                                                                                                                                                       |
| ---------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新しい表現       | 2.4秒    | 「話す」「動く」「空間に伝える」と手の軌跡の図版が順に空間へ広がる。                                                                                             |
| 目標の変化       | 1.2秒    | 「スライドを空間へ」から「動きも表現へ」を空間内で対置する。                                                                                                     |
| プロダクトの課題 | 1.2秒    | 「つくる」「そろえる」「届ける」を配置する。具体的な課題は口頭で補う。                                                                                           |
| 試作             | 1.6秒    | 「試す → 見る → 直す」と手の図版を再演する。                                                                                                                     |
| 発見             | 1.2秒    | 「動きと言葉をつなぐ」へ絞る。                                                                                                                                   |
| 比較の前半       | 約3.35秒 | 「回すだけなら？」と立方体の一回転。                                                                                                                             |
| 比較の後半       | 3秒      | 「動きとつなげると？」と文字・図版が順に現れ、立方体が移動する。実際の反応を示す表示は入れない。                                                                 |
| 最大の見せ場     | 5.4秒    | 文字・図版を残して立方体を回転・拡大・移動し、最後の構図を1秒維持する。                                                                                          |
| 技術紹介         | 1.8秒    | Control Plane（Workers・D1）、R2 のアセット、Realtime（Go）、Unity、Audience Web（Three.js・8th Wall）を配置し、準備・配信と gRPC / WebSocket の接続を線で示す。 |
| 閉幕             | 3.7秒    | 本編を0.7秒で消し、ブランドを1.3秒で中央・元の大きさへ戻す。0.8秒静止後、0.9秒で消す。                                                                           |

- 配置と文言は `show.scene.ts`、時間と移動は `show.timelines.ts`、進行は `show.flow.ts`、透明背景の描画は各 `*.component.tsx` で定義する。新しい図版はローカルの透明 PNG を使い、編集用の線画 SVG も `assets/` に保持する。外部画像の追加取得は不要。
- 閉幕後は何も表示しない `ordinary-slides` で待機する。通常スライドへの切替は発表環境で行い、次の `presenter.next` で MR の Flow を終了する。
- `pnpm --filter @unframe-dev/demo-presentation test` で Cue 進行・演出中の入力抑止・ロゴ維持・閉幕順序を検証する。型検査は同フィルターの `typecheck` を使う。

場面は `demo`（開幕・当初案・転換）、`expression`、`journey`、`comparison`（比較・見せ場）、`technology`（技術紹介・閉幕）、`ordinary-slides` の group に分ける。当初案、探索、比較、技術紹介の専用画像はそれぞれの group 所有とし、表示が終わってから group を退出する。探索から比較へは、最後の文字を0.35秒で消してから進む。

ロゴ、`Unframe`、再登場する3つの言葉と手の図版は presentation 所有にする。当初案の立方体も、回転中の転換後に Timeline が完了できるよう presentation 所有で保持する。

画像解放を行う配信側の変更は別 PR で扱う。その変更と組み合わせると、PNG の常駐対象は共有画像・現在の group・直接の次候補 group になる。全23枚のうち、この Source の最大同時対象は14枚（共有5枚・探索7枚・比較2枚）。統合した CLI build と Unity・Audience Web の配信選択は通過し、モデル内 Texture を含む最大 GPU 見積もりは約76.45 MiB（上限192 MiB）、binding は16（Audience 上限32）。実機のメモリ・起動時間は未確認。

## 本番前に確定すること

- 全体の持ち時間、待機中に話すセリフ、題材と文言の最終調整。
- 比較で語る実際の反応。現在の仮演出を実績として語らない。
- 発表者の身振りと `presenter.next` の操作タイミング。
- HMD・スマートフォン・ミラーリングでの配置、文字サイズ、モデルの大きさと視認性。
- 通常スライドと、発表者視点の動画・振り返り・今後の展望。
