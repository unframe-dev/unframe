# Audience リライト: 残る受け入れ

更新日: 2026-10-31。Audience 担当者向けに、現行の製品経路で残る実通信・実機受け入れをまとめる。

対応機能・会場設定・時計補償・配信環境の残作業は [接続・配信・実機受入計画](audience-web-app-plan.md)、現在の操作と構成は [Audience README](../../app/web/audience/README.md) を参照する。

## 実通信・実機の受け入れ

- [ ] 参加、カメラ許可、位置合わせ、待機、視聴、復旧、終了・退出の導線と主要な失敗状態を確認する。
- [ ] 実 WebSocket で途中参加、進行・停止・seek、再接続・再同期、資格・素材 URL 更新、終了を確認する。
- [ ] iPhone Safari／Android Chrome で権限拒否、背景復帰、追跡低下・再認識、動画・音声・GLB の同時負荷、繰り返し入退室、長時間視聴と資源解放を確認する。
- [ ] 受け入れ後に旧 UI・CSS・controller・購読処理・不要なテストの残存を確認し、見つかった不要物を削除する。

対象端末、配信環境、対象成果物、手順、測定値、残不具合を記録する。自動テストや過去の PoC 成果を、現行構成の公開環境・実機受入の代わりにしない。
