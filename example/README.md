# 成果発表会 MR デモ

6〜9枚目のメイン表示面は Stage の `z=0` に置き、MR では AprilTag と奥行きをそろえます。

## 4枚目の演出

×が消えたあと、`presenter.next` で4枚目へ進みます。

1. 左右の手の位置を残光で表示します。片手のコントローラーのトリガーを保持し、円を描きます。
2. `circle` の認識で軌跡を消し、舞台中央に立方体を出します（0.8秒）。
3. トリガーを一度離してから再び保持し、手を引いて前へ投げます。`throw` の認識で立方体が舞台前方へ飛び、「動きも、表現になる。」を表示します（1.8秒）。
4. `presenter.next` で次の場面へ進みます。

円・投げる動作の待機中や演出中は、`presenter.next` では進みません。
軌跡は円の認識前から表示し、トリガーを離している間も有効な左右の追跡位置を描きます。立方体の出現位置と飛ぶ経路は舞台上の固定配置です。

軌跡の表示には校正済みの Presenter Tracking と手の Anchor が必要です。追跡喪失中は新しい点を追加せず、再接続時に過去の軌跡は復元しません。円を待つ時間が60秒に達すると、軌跡と認識待ちを更新します。

## 5枚目の演出

5枚目は `journey-zone` から開始します。Local Editor の俯瞰視点で Presenter を右側の Zone（中心 `[1.4, 0, 0]`）へ移動すると、枠・文字・立方体が現れます。表示後に `spreadHands` を送ると枠が開き、文字は奥へ、立方体は手前へ広がります。続く「次へ」で「つくる・そろえる・届ける」へ進みます。Zone の内側から開始した場合は、一度外へ出てから入り直してください。

## 6〜9枚目の構成

5枚目の完了後は「次へ」で順に進みます。各ページは1.2秒で表示し、説明中は待機します。制作手順・開発経緯・技術構成は扱いません。

| 枚目 | 開始 Step        | 伝える内容                                                 |
| ---- | ---------------- | ---------------------------------------------------------- |
| 6    | `conditions`     | 見せる内容・発表者の操作・空間の位置合わせ・観客への共有   |
| 7    | `content-action` | 動作や立つ場所に応じて内容が変わり、身体を使った発表になる |
| 8    | `space-sharing`  | 発表者と観客が、表示位置と進行を共有して体験する           |
| 9    | `summary`        | 内容を、身体と空間を使って、観客に伝える                   |

Local Editor では各開始 Step を選び「選択位置から再生」で確認できます。まとめの後の「次へ」で表示を消し、通常スライドへの引き継ぎ待機に入ります。
