# 成果発表会 MR デモ

3つの Zone は中心を Stage の高さ 0.8m にそろえています。中心から上下1mの範囲に、Local Editor の初期高さの腰位置と、Quest で資料の高さを補正したときの立位のヘッドセット位置が入ります。

## オープニング

`presenter.next` で開始します。ロゴと Unframe は3秒で現れ、1.5秒保持した後、1.5秒で消えます（合計6秒）。終了後の `presenter.next` で立方体の説明へ進みます。

## 4枚目の演出

×が消えたあと、`presenter.next` で4枚目へ進みます。

1. もう一度 `presenter.next` を送ると、左右の手の位置を残光で表示します。片手のコントローラーのトリガーを保持し、円を描きます。
2. `circle` の認識で軌跡を消し、舞台中央に立方体を出します（0.8秒）。
3. トリガーを一度離してから再び保持し、手を引いて前へ投げます。`throw` の認識で立方体が左上へ移動します（1.1秒）。
4. 移動が終わると立方体の真下に「動きも、表現になる。」を、20cm下から浮き上がりながらフェードインします（0.7秒、自動）。
5. 左スワイプ（`swipeLeft`）で立方体とテキストを左へ流しながらフェードアウトします（0.8秒）。終了後、自動で次の場面の Zone 入場待ちへ進みます。

円・投げる動作・左スワイプの待機中や演出中は、`presenter.next` では進みません。
軌跡は円の認識前から表示し、トリガーを離している間も有効な左右の追跡位置を描きます。立方体の出現位置と移動経路は舞台上の固定配置です。

軌跡の表示には校正済みの Presenter Tracking と手の Anchor が必要です。追跡喪失中は新しい点を追加せず、再接続時に過去の軌跡は復元しません。円を待つ時間が60秒に達すると、軌跡と認識待ちを更新します。

## 5枚目の演出

5枚目は `journey-zone` から開始します。Local Editor の俯瞰視点で Presenter を枠の左端から60cm離れた左側の Zone（中心 `[-1.8, 0.8, 0]`）へ移動すると、枠・文字・立方体が現れます。「スライドを空間へ」は20cm下から浮き上がりながらフェードインします（0.8秒）。表示後に `spreadHands` を送ると、「スライドを空間へ」がフェードアウトします（0.3秒）。続いて枠が開き、立方体が右奥へ移動します（1.2秒）。移動が終わると「動きに連動する」が立方体より手前のステージ中央（高さ1.6m、奥行きZ=0.5m）に幅1.6mでフェードインします（0.7秒）。表示後に引くジェスチャー（`pullBackward`）を送ると、この文言と立方体が一緒に奥へ移動し、同じ割合で縮小しながらフェードアウトします（1秒）。終了後、自動でPoCの経緯へ進みます。Zone の内側から開始した場合は、一度外へ出てから入り直してください。

## PoCの経緯

「動きに連動する」と立方体の退場後、「このプレゼンに行き着くまで」が奥から中央へ出現します（0.7秒）。0.3秒保持し、左上へ移動・縮小します（0.8秒）。続いて「3Dを基準としたプレゼン → 円形に表示するプレゼン → 博物館のような演出のプレゼン」を順に表示し、開始から3秒で一覧になります。見出しの表示面は幅3.5m、各PoCは幅1.4mで、項目の中心間隔は1.65mです。文言と配置は `src/poc.scene.ts` で管理します。

一覧の表示後は `presenter.next` ごとに①、②、③へ注目を切り替えます（各0.4秒）。対象を1.25倍・不透明度100%にし、それ以外の項目と矢印は不透明度25%にします。演出中の追加入力は受け付けません。③まで注目を切り替えた後は、右スワイプ（`swipeRight`）で見出し・全項目・矢印・展示を右へ2m移動させながらフェードアウトします（0.8秒）。終了後、自動で反応の実演へ進みます。③の表示後は `presenter.next` では進みません。

各項目の強調に合わせて、①は立方体と説明パネル、②は観客側に円形に並べた6個の立方体、③は観客側の異なる位置と高さに置いた3個の立方体を表示します。注目先が変わると展示も0.4秒で入れ替わります。

## 反応の実演

1. 上スワイプ（`swipeUp`）で「浮遊感」が下から現れ（0.7秒）、上下に揺れ続けます。
2. 左スワイプ（`swipeLeft`）で「浮遊感」をその位置で止め、「感性」が右から現れます（0.7秒）。
3. 「感性」の表示後に右側の Zone（中心 `[1.8, 0.8, 0]`）へ入ると、先の2語が薄くなり「視線移動」が拡大します（0.8秒）。
4. 拡大中または拡大後の `presenter.next` で、その時点の見た目を保持します。もう一度 `presenter.next` を送ると、3語がフェードアウトし（0.6秒）、閉幕のZone入場待ちへ進みます。

「感性」の表示完了前から右側のZone内にいる場合は、一度外へ出て入り直してください。

## 閉幕

反応の実演の3語が消えた後、左側のZone（中心 `[-1.8, 0.8, 0]`）への入場を待ちます。Zoneへ入ると中央（高さ1.6m）に Unframe が2秒でフェードインし、表示を残したままFlowを終了します。閉幕に `presenter.next` は不要です。待機開始前からZone内にいる場合は、一度外へ出て入り直してください。
