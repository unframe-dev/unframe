# 成果発表会 MR デモ

## 4枚目の演出

×が消えたあと、`presenter.next` で4枚目へ進むと、何も表示せず待機します。

1. 手を動かすタイミングで `presenter.next`。波状の線を描き、立方体を出します（1.2秒）。
2. もう一度手を動かすタイミングで `presenter.next`。線が消え、立方体が右上へ移動・回転し、「動きも、表現になる。」を表示します（1.8秒）。
3. `presenter.next` で次の場面へ進みます。

各演出の完了後は操作を待ちます。演出中の `presenter.next` は受け付けません。
手の動作は認識せず、発表者が進行操作で演出を合わせます。
