## 分かったこと

元のログは88入力中85入力でタグを復号し、73件の姿勢を採用した。SDKは検出中NORMALを維持し、入力は768×1024。回転中のカメラ位置差は中央値10.1cm・最大31.3cmだが、カメラから見たタグ中心の差は中央値0.41cm・最大1.71cmだった。向きの推定差を逆行列にすると、約1.13mの距離がてこになり自己位置の大きな差として現れる。

現在の姿勢推定はAprilTag本体のネイティブ姿勢推定ではなく、復号した四隅をPOS.Positで初期化し、独自LMで再投影誤差を最小化するもの。元の2初期値が同じ局所解へ入る場合があった。

原因確認のオフライン実験で、SDK予測を追加初期値にすると元の解より再投影誤差が小さい解を得た。これは元の探索不足の証拠だが、SDKを真値とする根拠ではない。本番へSDK初期値は追加していない。

## 修正内容

各POSIT初期値からカメラ→タグ中心の視線単位ベクトルrと、タグ面の法線nを求め、`n' = 2(r·n)r − n`で視線軸に関して反転した法線を追加初期値にする。Quaternionの正回転で元姿勢からn'へ回す。鏡映行列をそのまま姿勢にしない。全候補を同じ四隅・K・再投影目的関数でLM精緻化し、誤差で選ぶ。

2初期値から最大4初期値へ増やす。これは別の局所解へ探索を広げる手法であり、IPPE実装・全解列挙・正解保証ではない。SDKの姿勢・過去フレーム・平滑化・向きの事前固定は使用しない。カメラ行列・画像寸法も変更しない。

候補同士が0.1rad超離れ、誤差差が`max(0.2px, 最小誤差×0.25)`以内なら、従来と同じ閾値で曖昧として保留する。探索する候補が増えたため、従来見逃した曖昧性も検出できる。次点がないことや候補1つは、向きの高精度の保証ではない。

全88入力では、採用73→71、曖昧11→14、再投影誤差除外1→0、未検出3→3。曖昧性で参照がリセットされるため、旧・新の比較ペアと母数は同一ではない。集計差を純粋な精度改善率と扱わない。レポートに同じreferenceFrameIdの組も別集計するが、参照姿勢自体も再計算される点は変わらない。主な修正根拠は同じ角座標に対し、見逃していたより低誤差の解を得られたこと。

角を1成分ずつ±0.25px変える16条件、焦点距離±1%、主点cx/cy±1pxの決定的な感度試験も実施した。これらは実測ノイズ幅ではない。修正後も、採用された一部の入力では±0.25pxに対し約6〜10°の解変化を生じる。Kの小変更でも局所解の切替は起こり得る。Kを変更しなくても大ジャンプの一部が減るが、物理カメラの較正の正しさを証明してはいない。残る向きの不安定性・約10cmの目標未達は継続課題。

## ログと操作

比較ログはschema15、タグ単独ログはschema9。top-level `poseEstimatorPolicy`へ手法・初期値数・閾値を保存する。各`tagLocalization.poseDiagnostics`は以下を保持する。

- `attemptedSeeds`、`refinedSeeds`: 初期値数と有効な精緻化結果数。refinedは数学的収束の保証ではない。
- `distinctSolutions`: 探索で得られた向きの異なる解の数。全ての可能解の数ではない。
- `bestSeedIndex`、`ambiguityThresholdPixels`。
- `nextDistinct`: 次点の姿勢・再投影誤差・最小解との誤差差・回転角差。

曖昧／再投影誤差超過の場合も診断を保存する。未検出や推定不能はnull。画像画素は保存しない。操作は従来通り1回の静止→回転→横移動でよく、追加の実機試験条件は増やさない。

再生コマンド（出力先を明示する）:

```bash
pnpm --filter @unframe/audience exec node scripts/analyze-pose-log.mjs /path/to/audience-anchor-comparison-log.json /tmp/audience-pose-replay.json
```

記録済みの旧結果と現在の推定器による再計算を比較する。省略されたフレームの補完はせず、入力のリング欠落件数を出力へ引き継ぐ。

## 根拠資料

- [IPPE著者の実装・解説](https://github.com/tobycollins/IPPE): 平面姿勢の2解と、投影がアフィンに近い場合の曖昧性。
- [OpenCV公式PnP文書](https://docs.opencv.org/4.13.0/d5/d1f/calib3d_solvePnP.html): 正方形向けIPPE_SQUAREとカメラ行列・点順序。
- [AprilTag公式姿勢API](https://github.com/AprilRobotics/apriltag/blob/master/apriltag_pose.h): 1または2姿勢の探索と誤差。独自POS.Posit＋LMとは異なる。

これらは平面姿勢の曖昧性を調べる根拠であり、今回の独自反転初期値が公式推定器と同等だという主張ではない。
